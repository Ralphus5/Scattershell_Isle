# 🐚 Scattershell Isle

Scattershell Isle is a top-down 2D Zelda-like videogame.

## 🎮 Game Concept

You are stranded on a curious Island harboring a multitude of shells. There are many enemies as well and several dungeons with bosses.

---

## 🕹️ Controls

Keybindings are remappable for the keyboard. By default you walk with WSDA on keyboard and with d-pad or left stick on controller. Press enter or bottom most right face controller button for attack.
